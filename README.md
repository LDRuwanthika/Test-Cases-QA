# Test Cases - QA
This repository includes organized test case spreadsheets for different systems, showcasing manual QA test case design.

## 📁 Contents

- **Lassana_TestCases.xlsx**  
  Test cases covering product search, cart management, checkout process, and feedback submission for Lassana.com.

- **Facebook_TestCases.xlsx**  
  Sample test cases focused on login/logout, profile updates, post creation, and notification checks.

## ✅ Purpose

To demonstrate skills in identifying test scenarios, writing test cases, and ensuring comprehensive test coverage across different platforms.

---

🛠️ Created as part of hands-on QA learning and project documentation.
